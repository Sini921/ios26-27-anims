# iOS 27 Animations

Твик для rootless jailbreak, переносящий анимации открытия и закрытия приложений, эффект джина и анимацию иконок при открытии шторки уведомлений на более ранние версии iOS. Эффекты можно включать отдельно в Настройках → iOS 27 Animations. Версия 1.5.1 добавила регулировки скорости и силы эффектов, прозрачную шторку, сброс настроек и респринг; 1.5.2 исправляет обрезку увеличенных SnowBoard иконок во время перехода.

Пакет `com.bazik1337.ios2627anims` собирается для arm64/arm64e с минимальной версией iOS 15.0. Для страницы настроек нужен PreferenceLoader. Проверка работы версии 1.5.2 на устройстве ещё требуется.

Готовый `.deb` доступен в [GitHub Releases](https://github.com/ba31k/ios26-27-anims/releases). Сборка из исходников:

```sh
make -C codex/CodexGenie27 package FINALPACKAGE=1 THEOS=/path/to/theos
```
